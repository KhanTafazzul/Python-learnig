================================================================================
                    PYTHON LIBRARIES: RANDOM & DATETIME
================================================================================

This document covers two essential built-in Python libraries:
1. `random`   - Used for generating pseudo-random values and choices.
2. `datetime` - Used for managing dates, times, and time arithmetic.

================================================================================
                         SECTION 1: THE RANDOM LIBRARY
================================================================================

1. DEFINITION:
   The `random` library is a built-in Python module that generates pseudo-random 
   numbers, shuffles lists, and makes random selections from sequences. It uses 
   the Mersenne Twister algorithm as its core generator.

2. BASIC SYNTAX:
   Always import the module at the beginning of your script:
   ```python
   import random
   ```

3. KEY FUNCTIONS & USAGE:

   a. random.random()
      - Returns: A random float in the range [0.0, 1.0) (excluding 1.0).
      - Syntax:
        ```python
        value = random.random()
        print(value)  # e.g., 0.374829104
        ```

   b. random.uniform(a, b)
      - Returns: A random float between 'a' and 'b' (inclusive or exclusive depending on rounding).
      - Syntax:
        ```python
        value = random.uniform(10.5, 20.0)
        print(value)  # e.g., 14.829104
        ```

   c. random.randint(a, b)
      - Returns: A random integer between 'a' and 'b' (inclusive of both endpoints).
      - Syntax:
        ```python
        roll = random.randint(1, 6)
        print(roll)  # e.g., 5
        ```

   d. random.randrange(start, stop, step)
      - Returns: A randomly selected element from range(start, stop, step).
      - Syntax:
        ```python
        # Get a random even number between 0 and 10 (0, 2, 4, 6, 8)
        num = random.randrange(0, 10, 2)
        print(num)
        ```

   e. random.choice(sequence)
      - Returns: A random element from a non-empty list, tuple, or string.
      - Syntax:
        ```python
        choices = ["Rock", "Paper", "Scissors"]
        comp_move = random.choice(choices)
        print(comp_move)  # e.g., "Paper"
        ```

   f. random.sample(sequence, k)
      - Returns: A list of 'k' unique elements chosen from a sequence (sampling without replacement).
      - Syntax:
        ```python
        cards = ["Ace", "King", "Queen", "Jack", "10", "9"]
        hand = random.sample(cards, 3)
        print(hand)  # e.g., ['King', '10', 'Ace']
        ```

   g. random.shuffle(list)
      - Action: Shuffles the items of a list in-place (modifies the original list directly).
      - Syntax:
        ```python
        numbers = [1, 2, 3, 4, 5]
        random.shuffle(numbers)
        print(numbers)  # e.g., [4, 1, 5, 2, 3]
        ```

   h. random.seed(a)
      - Action: Initializes the random number generator. Using the same seed will produce the exact same sequence of "random" numbers every time.
      - Syntax:
        ```python
        random.seed(42)
        print(random.randint(1, 10))  # Will always output 2 when rerun!
        ```


================================================================================
                        SECTION 2: THE DATETIME LIBRARY
================================================================================

1. DEFINITION:
   The `datetime` module provides classes for manipulating dates and times in both 
   simple and complex ways. It is extremely useful for timestamping logs, tracking 
   transaction times, or calculating differences between dates.

2. BASIC SYNTAX:
   Import the classes directly from the module:
   ```python
   from datetime import datetime, date, time, timedelta
   ```

3. KEY CLASSES & THEIR FUNCTIONS:

   a. date Class (Year, Month, Day)
      - Represents calendar dates.
      - Syntax:
        ```python
        # Get today's date
        today = date.today()
        print(today)         # e.g., 2026-08-30
        print(today.year)    # 2026
        print(today.month)   # 8
        print(today.day)     # 30

        # Create a custom date
        custom_date = date(2025, 12, 25)
        print(custom_date)   # 2025-12-25
        ```

   b. time Class (Hour, Minute, Second, Microsecond)
      - Represents time independent of any date.
      - Syntax:
        ```python
        # Create a custom time: time(hour, minute, second)
        meeting_time = time(14, 30, 0)
        print(meeting_time)  # 14:30:00
        ```

   c. datetime Class (Combines Date & Time)
      - Represents a single point containing both date and time values.
      - Syntax:
        ```python
        # Get current date & time
        now = datetime.now()
        print(now)           # e.g., 2026-08-30 10:32:00.123456

        # Create a custom datetime
        event = datetime(2026, 12, 31, 23, 59, 59)
        print(event)         # 2026-12-31 23:59:59
        ```

   d. timedelta Class (Duration & Date Arithmetic)
      - Represents the difference between two date or datetime instances (a duration of time).
      - Syntax:
        ```python
        # Add or subtract days/weeks/hours/minutes
        today = date.today()
        ten_days_later = today + timedelta(days=10)
        three_weeks_ago = today - timedelta(weeks=3)

        print("10 Days Later:", ten_days_later)
        print("3 Weeks Ago:", three_weeks_ago)

        # Difference between two datetimes
        time_a = datetime(2026, 8, 30, 10, 0, 0)
        time_b = datetime(2026, 8, 30, 12, 45, 0)
        duration = time_b - time_a
        print(duration)            # 2:45:00
        print(duration.seconds)    # 9900 (total seconds)
        ```

4. FORMATTING & PARSING DATE STRINGS (EXTREMELY IMPORTANT)

   a. strftime() — Convert datetime to a formatted string (Date ➔ String)
      - Use format codes (directives) starting with '%' to customize the output.
      - Syntax:
        ```python
        now = datetime.now()
        formatted = now.strftime("%Y-%m-%d %H:%M:%S")
        print(formatted)  # Outputs: 2026-08-30 10:32:00
        ```

   b. strptime() — Parse string into a datetime object (String ➔ Date)
      - Converts structured text back into a manipulable datetime object.
      - Syntax:
        ```python
        date_str = "30-08-2026 10:32"
        parsed_date = datetime.strptime(date_str, "%d-%m-%Y %H:%M")
        print(parsed_date)  # Outputs: 2026-08-30 10:32:00
        ```

   Common Formatting Directives Table:
   | Code | Meaning | Example |
   | :--- | :--- | :--- |
   | `%Y` | Year (4-digit) | `2026` |
   | `%y` | Year (2-digit) | `26` |
   | `%m` | Month (2-digit) | `08` |
   | `%B` | Month (Full name) | `August` |
   | `%d` | Day of month (2-digit) | `30` |
   | `%H` | Hour (24-hour clock) | `14` |
   | `%I` | Hour (12-hour clock) | `02` |
   | `%M` | Minute (2-digit) | `32` |
   | `%S` | Second (2-digit) | `00` |
   | `%p` | AM or PM | `PM` |
