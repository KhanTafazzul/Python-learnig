# 🌶️ Flask Web Development Notes Index

Welcome to the **Flask Backend & Web Development** learning section (Month 5).

## 📋 Topics Outline
1. **Flask Fundamentals**: App initialization, routing (`@app.route`), HTTP methods (`GET`, `POST`)
2. **Jinja2 Templating**: Template rendering, passing context variables, loops, conditionals, template inheritance
3. **Forms & Request Handling**: Extracting query params and form data with `request.form` / `request.args`
4. **Database Integration**: SQLite3 & SQLAlchemy models, CRUD operations (Create, Read, Update, Delete)
5. **Session Management & API Endpoints**: User sessions, flash messages, JSON API endpoints with `jsonify`
