         MODULES, PACKAGES & VIRTUAL ENVIRONMENTS (venv)
================================================================================

1. TOPIC: MODULAR PROGRAMMING & DEPENDENCY MANAGEMENT
--------------------------------------------------------------------------------
Key Concepts:

- MODULES:
  - Any Python file (`.py`) containing variables, functions, or classes that can be imported and reused in other files.
  - Usage: `import my_module` or `from my_module import my_function`.

- PACKAGES:
  - A directory containing multiple modules and an `__init__.py` file (which tells Python that this directory is a package).

- VIRTUAL ENVIRONMENT (venv):
  - An isolated workspace for your Python projects.
  - Why use it? It prevents dependency conflicts between different projects (e.g., Project A needs Django 3.0, but Project B needs Django 5.0).
  - Commands to create & activate on Windows:
    - Create:   `python -m venv venv`
    - Activate: `venv\Scripts\activate`

- PIP & PACKAGE MANAGER:
  - `pip` is the package installer for Python (used to install external libraries like `requests`, `colorama`, `pygame`).
  - Command to install: `pip install <package-name>`
  - Save dependencies: `pip freeze > requirements.txt`
  - Install dependencies: `pip install -r requirements.txt`
